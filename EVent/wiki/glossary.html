Glossary

Short definitions of the terms used throughout the wiki and the code.

TermMeaning
Admin eventA ServerAdminEvent package handled by the node itself (EventAdded, ListEvents, …). More
AwaitReadyA NOTES system function that answers once the node's execution gate is open. It's used as a readiness probe. More
Child (NOTES)A registered field whose type is itself composite (its descriptor is non-empty). It is recursed into when serializing and flattening.
ClientAnything implementing IEVentClient: a remote link (QueuedClient) or local code (LocalCallbackClient).
dRPCDistributed RPC: a function call delivered to every provider in the network. It returns every answer.
Established descriptorA NOTESEventDescriptor the network has agreed on for an event ID.
EventIDThe string naming an event or function. IDs are flat strings; a namespace node gives a network's IDs a dotted prefix (Minecraft.Player.Health).
Execution gateExecutionGate: a latch that pauses typed operations during network merges.
CapThe maximum element count of a NOTES collection, part of its type (Cat[<=16]). It comes from a collection definition (NOTESDescriptor.Collection(maxCount)) or from the collection field's registration (maxCount); if both, they must be equal.
Collection (NOTES)A BinaryConvertibleCollection<T> (any INOTESCollection) field or event type. Its element type, and its optional cap, are part of the NOTES type: Cat[], Cat[<=16].
ExpectedThe field of NOTESEventDescriptor holding the event's canonical signature.
FlexibleSerDesNOTESFlexibleSerDes: the NOTES description of one C# type, meaning its signature plus a serializer for the canonical layout.
HandleEVentFunctionHandle (FunctionCallID + ClientID). Identifies one pending dRPC call on one hop.
InterconnectA link between two nodes.
InterestThe fact that a client wants packages for an EventID. It spreads through EventAdded floods.
Leaf (NOTES)A type with an empty descriptor that isn't a collection (a primitive, a string, NOTESVoid, a custom leaf). It is serialized with its own ToBytes.
Optional fieldA field registered with RegisterOptionalField: it may be null (sent as absent) and is marked ? in the signature. It's what lets a type contain itself directly.
Record (NOTES)A type that registers fields. It has one Name{field:Type,...} definition in the signature and is written as its fields in sorted order.
SignatureThe type graph NOTES agrees on for an event: one =Root entry plus one definition per record type, sorted. See Signature grammar.
Local layerThe LocalCallbackClient returned by EVentNode.AddLocalCallbackLayer().
Network / sub-networkAll nodes reachable through links. It must be a tree. A namespace makes a network a named sub-network of another.
NodeAn EVentNode (router) or a TypeSafeEVentNode (typed facade around one).
NOTESNo Overhead Type Enforcement System. More
NOTESVoidThe unit type: serializes to a single 0x00 byte so that “returned nothing” still counts as an answer.
PackageThe framed wire message: EventID + PackageType + payload.
Potential descriptorA proposed descriptor held during the two-phase agreement, before Finalize. It expires after ProposalTimeToLive.
Abort (NOTES)AbortNOTESDescriptor: withdraws one exact proposal from every node that accepted it.
Proposal TTLTypeSafeEVentNode.ProposalTimeToLive: how long a pending proposal blocks competitors. The default is 5 s.
Probe connectionThe temporary link TryEstablishConnection opens to inspect a remote network before linking for real.
RandomWeightA random tie-breaker in NOTESEventDescriptor that decides between competing proposals.
TransportAn ICommsProtocol implementation (TCPServer, SerialServer).
AnnotationA field's documentation: description, range and default (NOTESFieldAnnotation). Not part of the type; it travels with the agreed descriptor. More
EndpointAn event or function of the network as discovery and NON see it: its ID, kind and agreed types (EndpointDescription, NONEndpoint).
Firewall nodeTwo typed nodes joined by a link that lets through only the events and calls a FirewallPolicy allows, per direction. More
Frame (scripting)The generated, read-only C# a script is written against: a class per record type and the Handle signature. More
Import (namespace)A name of the parent network a namespace uses inside, unchanged (World covers World.*). Nothing else of the parent network is visible inside. More
Namespace nodeTwo typed nodes joined by a renaming link: inner X is ns.X outside. More
NONNOTES Object Notation: NOTES' wire format and type descriptions (the signature, the layout it defines, the JSON that describes it). More
NONObject / NONValueA value of a NON type without a C# class: a record as a slot array, a value as a small struct. More
Prefix routeAn interest entry ending in .*: everything under the prefix is routed to the client that announced it. One entry for a whole namespace. More
Scripting nodeA typed node that runs C# scripts, compiled with Roslyn, as handlers between endpoints, managed from a local web page. More
Leaf nodeA node in another language (C++ so far) with one link to a router and its own NOTES implementation; it routes nothing. More
RouterThe C# node a leaf links to: the interconnect between languages, machines and transports. More
