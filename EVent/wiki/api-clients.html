Clients & helpers

LocalCallbackClient, IEVentClient, QueuedClient, ExecutionGate and the callback wrappers.

LocalCallbackClient

namespace Event.CoreFunctionality LocalCallbackClient.cs

Your code's endpoint inside a node, obtained from EVentNode.AddLocalCallbackLayer(). From the node's point of view it's just another IEVentClient. Internally it owns a channel that carries outgoing packages to the node, maps of event callbacks and functions, and NodeEvents (the IDs the rest of the network is interested in).

public void HookEvent<T>(string eventID, Action<T> callback, bool notifyNode = true) where T : IBinaryConvertible, new()

Subscribes to raw event eventID. On the first callback for an ID, an EventAdded is sent to the node (unless notifyNode is false). Callbacks run on the thread pool. A payload that fails T.FromBytes is silently dropped.

local.HookEvent("Temperature", (BinaryConvertibleFloat t) => Console.WriteLine($"{t.value} °C"));
public void HookEvent<T>(string eventID, Action<T> callback, Func<T, byte[], bool> customDeserialize, bool notifyNode = true)

The same, with a custom deserializer that fills the provided instance.

public void UnHookEvent<T>(string eventID, Action<T> callback)

Removes the callback, matched by the delegate instance you passed to HookEvent. When the last callback for the ID goes, and no function is registered for it either, an EventRemoved is sent. Keep the delegate in a variable if you want to unhook it later.

public void FireEvent<T>(string eventID, T data, PackageType packageType = PackageType.Data) where T : IBinaryConvertible, new()

Calls local subscribers directly (on the thread pool, with the same object instance, no serialization), and sends a package to the node only if another client is interested (NodeEvents) or the type is ServerAdminEvent. Fire-and-forget, but it blocks while more than QueuedClient.MaxQueuedDataBytes of this layer's raw events wait for the node (back-pressure).

public void FireEvent<T>(string eventID, T data, Func<T, byte[]> customSerializer, PackageType packageType = PackageType.Data)

The same, with a custom serializer for the network copy.

public void RegisterFunction<TInput, TResult>(string EventID, Func<TInput, TResult> func) where TInput : IBinaryConvertible, new() where TResult : IBinaryConvertible, new()

Provides dRPC function EventID. The first registration for an ID sends an EventAdded. Several functions per ID are allowed, and each contributes a result. Each incoming call runs as a thread-pool task, never on the thread that delivers it (a link's reader, or the caller), so a handler may itself call functions, even back over the link its call came from. Return null to contribute no answer. If the handler throws, the exception is logged and the node contributes no answer; the call still completes and the link stays up (C33).

public void RegisterFunction<TInput, TResult>(string EventID, Func<TInput, TResult> func, Func<byte[], TInput, bool> inputDeserializer, Func<TResult, byte[]> outputSerializer)

RegisterFunction with custom (de)serializers. This is what NOTES uses for typed events.

public void RegisterAsyncFunction<TInput, TResult>(string EventID, Func<TInput, Task<TResult>> func) public void RegisterAsyncFunction<TInput, TResult>(string EventID, Func<TInput, Task<TResult>> func, Func<byte[], TInput, bool> inputDeserializer, Func<TResult, byte[]> outputSerializer)

The same for a handler that works asynchronously: the answer is sent when its task completes, and no thread is held while it awaits, for example a nested CallFunctionAsync (C32).

local.RegisterAsyncFunction<BinaryConvertibleInt32, BinaryConvertibleInt32>("Total", async n =>
{
    var parts = await node.CallFunctionAsync<BinaryConvertibleInt32, BinaryConvertibleInt32>("Part", n);
    return parts.Sum(p => p.Value);
});
public bool UnregisterFunction(string EventID, Delegate original)

Removes every registration of original (the delegate passed to RegisterFunction or RegisterAsyncFunction) for the ID, and returns whether there was one. The node is sent an EventRemoved only when the layer has neither a function nor an event callback left for the ID.

public void SendPackage(Package package)

Writes a raw package to the node, bypassing the NodeEvents filter. Used to inject admin packages such as CreateInterconnect.

public void CallFunction(string eventID, EVentFunction input)

Runs local functions only, appending their results to input.ReturnValues. Unused in the codebase (I-29). For network calls use EVentNode.CallFunction.

public int ID { get; } public Task Send(Package package) public Task<Package?> ReadPackage() public void Shutdown()

The IEVentClient implementation, used by the node. Send is where network packages turn into callbacks and function executions. If no function is registered for the ID (a raw subscriber sharing it), a FunctionCall is still answered, with no values (before commit 8c7a5cf it got no reply and the call hung). Shutdown does nothing.

IEVentClient

namespace Event.CoreFunctionality IEVentClient.cs

public interface IEVentClient
{
    int ID { get; }                  // process-local counter (not unique across client kinds)
    Task Send(Package package);      // node -> client
    Task<Package?> ReadPackage();    // client -> node; null ends the read loop
    void Shutdown();
}

Implement it to attach something unusual to a node, such as a test harness, a bridge to another bus, or a recorder. Hand it over with EVentNode.AcceptClient.

QueuedClient

namespace EVent.CoreFunctionality QueuedClient.cs

public QueuedClient() public QueuedClient(IStreamClient client) public void SetClient(IStreamClient client)

A link wrapper around an IStreamClient. The send pump starts when a stream is supplied.

public Task Send(Package package)

Enqueues and returns. For a raw event (Data) the task completes once the link's send queue holds less than MaxQueuedDataBytes of raw events again (back-pressure); everything else completes at once, and keeps its place in the queue. Never throws: after the link has shut down, packages are silently dropped. Packages with an empty EventID are dropped by the pump.

public static long MaxQueuedDataBytes { get; set; } = 8 MiB

How many bytes of raw events may wait in a link's send queue, and in its receive queue, before the sender waits and the link stops reading its stream (so the peer's sends wait in turn). The node handles a link's raw events in order and waits for a full link downstream, so a slow link slows its publishers instead of filling memory (harness C24). Typed events, calls and the protocol's own messages are never held back. Process-wide. The local layer uses the same limit for what its publishers queued.

public Package? ConnectionInfo { get; set; } public bool Faulted { get; set; }

ConnectionInfo is the connection info a node dialed this link with (null for accepted links); it becomes LinkFault.Redial. Faulted is set when the node drops the link for a fault, after which nothing read from it is processed.

public Task<Package?> ReadPackage() public Task<Package?> ReadPackage(CancellationToken cancellation)

The next package from the link, or null once it has ended. One pump reads the stream into a queue as soon as the stream is supplied, and readers take from the queue, so cancelling a read never consumes or splits a frame. That's what lets a link change owners (EVentNode.DetachClient). A stream error (such as a malformed frame) is rethrown to the reader.

public void Shutdown() public void Abort()

Shutdown flushes everything already queued, then closes the stream; it's safe to call more than once. Abort closes the stream immediately without flushing.

ExecutionGate

namespace Event.CoreFunctionality ExecutionGate.cs

A latch with an in-flight counter, used by TypeSafeEVentNode so a merge can pause typed operations.

MemberBehaviour
EnterAsync() / Enter()Wait until the gate is open, then count yourself as active. Checking and counting are one atomic step.
Leave()Stop counting yourself; completes a pending drain when the count reaches 0.
Close() / Open()Stop or allow new entries.
WaitForDrainAsync() / WaitForDrain()Complete when nothing is inside.
IsOpenWhether new entries go straight in.

The async forms hold no thread while they wait; the plain forms block. (Before commit 2c9a853 the gate had race windows between checking and waiting, and could deadlock a drain on the first cycle; N23 now runs hundreds of thousands of cycles.)

NativeCallback / NativeFunction

namespace Event.CoreFunctionality NativeCallback.cs

Type-erased wrappers stored by LocalCallbackClient. NativeCallback holds fromNetwork(Package) and fromLocal(IBinaryConvertible) delegates. NativeFunction holds the original delegate plus a typeErased: Func<IBinaryConvertible, Task<byte[]>> (synchronous handlers return a completed task) that accepts either a Package or a direct TInput. Equality is by hash code of the delegates. You won't normally touch these.
