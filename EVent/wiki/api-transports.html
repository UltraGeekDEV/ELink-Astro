Transport classes

The ICommsProtocol and IStreamClient implementations, discovery, and utilities.

Conceptual overview: Transports.

ICommsProtocol

namespace EVent.Connections ICommsProtocol.cs

void OnClientAccepted(Action<QueuedClient> action) void Run() Task<QueuedClient?> EstablishInterconnect(Package package) void Stop()

EstablishInterconnect receives the whole CreateInterconnect admin package. Parse package.Data as the nested connection-info Package.

IStreamClient

namespace EVent.Connections.Models IStreamClient.cs

Task Send(byte[] data) Task<Package?> ReadPackage() void Close()

ReadPackage returns null only when the link is finished. The node removes the client when it sees null.

TCPServer

namespace EVent.Connections.TCP TCPServer.cs

public TCPServer(IPAddress listeningAdress, int port) public TCPServer(IPAddress listeningAdress, int port, params string[] serverBroadcastedIDs)

The second overload also answers multicast discovery for each ID once running.

public IPAddress? AdvertisedAddress { get; set; }

The IPv4 address discovery replies advertise. By default the listening address when that's a specific IPv4 address, otherwise IPUtils.GetLocalIPv4(). Set it before Run on a machine with several networks.

public int Port { get; }

The port the server listens on: the one it was given, or for port 0 (any free port) the one the system assigned once Run has started it. Discovery advertises this port, and SourcePort is compared with it.

public void Run()

Binds the port (throws if it's taken), starts accepting on a background task, and starts the discovery responders. Does nothing if already running; after Stop it starts again.

public Task<QueuedClient?> EstablishInterconnect(Package package)

Handles "TCP" (TCPConnectionData, when SourcePort is 0 or this server's port) and "TCPAUTO" (a server ID resolved through discovery). Returns null for other types or on failure.

public void Stop()

Stops accepting, releases the port and stops the discovery responders. Links already made belong to the node and are left alone.

Discovery

namespace EVent.Connections.UDP ServerTCPBroadcast.cs

public class ServerTCPBroadcast public static int EVentTCPConenctionBroadcastPort = 8563; public static string EVentBroadcastGroup = "239.255.12.85"; public ServerTCPBroadcast(string serverID, string ip, string port) public void Start() public void Stop()

Joins the group and answers requests whose EventID equals serverID until stopped. If the machine can't join the group, that's logged and the server just can't be discovered.

public class ClientTCPDiscovery public static TimeSpan RetryInterval { get; set; } // default 1 s public static TimeSpan Timeout { get; set; } // default 10 s public static IPEndPoint? GetTCPServer(string ServerID) public static IPEndPoint? GetTCPServer(string ServerID, TimeSpan timeout)

Sends a request, again every RetryInterval, and returns the endpoint from the first valid reply for ServerID (replies carrying another ID are ignored). If nobody has answered within timeout (default Timeout; System.Threading.Timeout.InfiniteTimeSpan asks forever), it returns null (T08). A merge stops waiting for it even sooner, after MergeStepTimeout.

Serial

namespace Event.Connections.Serial SerialServer.cs

public class SerialServer : ICommsProtocol public SerialServer(string ServerID)

Scans the serial ports every second and handshakes with each new port using ServerID. EstablishInterconnect always returns null.

public class SerialStreamClient : IStreamClient public static SerialStreamClient? TryConnect(string port, string serverID)

Opens the port at 9600 baud with a 1 s read timeout, performs the handshake, and switches baud rate. See I-09 and I-16.

Utilities and legacy

public static class IPUtils { public static IPAddress GetLocalIPv4(); }

Namespace EVent.Utils. Returns the local address of a UDP socket “connected” to 8.8.8.8 (no packet is sent); without a default route, the first IPv4 address of an active non-loopback interface; failing that, loopback. Never throws.

public class TCPClientConnection

Legacy standalone client from before ICommsProtocol. Not used by the node (I-29).

internal class TCPStreamClient : IStreamClient

Wraps a TcpClient stream and uses Package.ReadPackage(Stream).
