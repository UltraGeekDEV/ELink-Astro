Serialization types

IBinaryConvertible, Package, the primitives, and the NOTES and dRPC data types.

Everything here derives from IBinaryConvertible. Namespaces are split: primitives and Package are in EVent.Connections.Models.BaseBinaryConvertibles, and the NOTES and dRPC types are in Event.Connections.Models.BaseBinaryConvertibles (I-30). Byte layouts are on Wire format.

IBinaryConvertible

public abstract class IBinaryConvertible { public abstract string Name { get; } public abstract NOTESDescriptor Descriptor { get; } public abstract bool FromBytes(ref Span<byte> data); public abstract byte[] ToBytes(); }

See Defining NOTES types. FromBytes must consume exactly its bytes, advance the span, and return false (rather than throw) on bad input.

public class FieldDescriptor { string Name; string FieldType; Func<IBinaryConvertible, IBinaryConvertible> FieldProvider; Func<IBinaryConvertible>? Factory; int? MaxCount; Action<IBinaryConvertible, IBinaryConvertible?>? Setter; bool Optional; NOTESDescriptor? MemberDescriptor; int Order; }

One leaf or collection registration. FieldType is the member type's Name. Factory creates an instance of the declared type, which NOTES uses as the type template. MaxCount is a field cap (collections only). Setter is set for optional fields (Optional). MemberDescriptor and Order let the plain serializer decide record-vs-leaf when it runs, so mutually recursive types get the same layout whatever static constructor ran first.

public class NOTESChild { string FieldName; NOTESDescriptor FieldDescriptor; Func<IBinaryConvertible, IBinaryConvertible> FieldProvider; Func<IBinaryConvertible>? Factory; Action<IBinaryConvertible, IBinaryConvertible?>? Setter; bool Optional; int Order; }

One record registration. Factory creates an instance of the declared type for NOTES; Setter is set for optional records.

public interface INOTESCollection IBinaryConvertible CreateElement(); IEnumerable<IBinaryConvertible?> Items { get; } void SetItems(IReadOnlyList<IBinaryConvertible> items);

Namespace EVent.Connections.Models.BaseBinaryConvertibles. Marks a type as a NOTES collection: CreateElement gives the element type's template (and the target for each element read), Items and SetItems read and replace the elements. A collection's cap lives in its descriptor (NOTESDescriptor.Collection) or on the field that holds it. BinaryConvertibleCollection<T> implements it.

public class NOTESEventDescriptor : IBinaryConvertible

The negotiated descriptor of one event or function: Expected (input signature), EventID, Returns (return signature) and a private RandomWeight. Constructors: (), (expected, eventID) for an event (Returns = VoidSignature, ["=Void"]), (expected, eventID, returns) for a function. Equals is exact, ordered equality with a matching GetHashCode. IsSameProposal(other) additionally requires the same random weight (used by Abort). Wins(other) is this.RandomWeight < other.RandomWeight (I-24). Documentation travels with it and isn't compared: Description, InputAnnotations, ReturnAnnotations (NOTESFieldAnnotations). IsEvent tells an event from a function, ToJson() renders it. Details on NOTES events reference. NOTESSignatureJson.ToJson(signature, annotations) turns any signature into the JSON type description without the C# type; NONSchema.FromJson reads it back (NON).

dRPC envelopes

public class EVentFunction : IBinaryConvertible { EVentFunctionHandle Handle; Package Parameters; BinaryConvertibleCollection<Package> ReturnValues; }

The payload of FunctionCall / FunctionReturn. Parameters.Data is the serialized input. Each entry of ReturnValues is a package whose Data is one serialized result. Available to OnFunctionCall handlers.

public class EVentFunctionHandle : IBinaryConvertible { BinaryConvertibleUInt64 FunctionCallID; BinaryConvertibleInt32 ClientID; }

Identifies a pending call on one hop. new EVentFunctionHandle(clientID) takes the next ID from a static, process-wide counter. Equality and hashing use both values.

Other payloads

public class TCPConnectionData : IBinaryConvertible { string TargetIP; int TargetPort; int SourcePort; }

Parameters for ConnectionTypes.TCP. It's text-encoded (ip:targetPort:sourcePort, parsed from the right so IPv6 addresses work) and not composable: it consumes the rest of the buffer. SourcePort picks which of the dialing node's TCP servers makes the link: the one listening on that port. 0 (the default, and what TCPConnectionData(IPEndPoint target, int sourcePort = 0) gives you) lets any of them dial; on a node with several TCP servers, set it so only one does.

internal class BroadcastHandshake : IBinaryConvertible

The discovery reply payload (IP, port and CRC-32). Internal.

public class TypedEvent : IBinaryConvertible

Namespace Event.Connections.Models. It has an EventID and a newline-joined type description. Unused, probably an earlier design (I-29).

public class ExcessivePackageSizeException : Exception

Thrown by Package.ToBytes above MaxPackageSize.
